== 1.1.模式

**模式**是Vi系编辑器的精华所在。这个概念在第0篇已经提到过，这里要讲的是每个模式的具体操作方式。



=== 1.1.1.模式切换

大部分模式切换都在NORMAL模式下进行。

|===
|目标模式 |快捷键 |需求模式

|NORMAL
|kbd:[ESC]
|-

|INSERT
|kbd:[I] / kbd:[A] / kbd:[O]
|NORMAL

|COMMAND
|kbd:[:] ( kbd:[SHIFT+;] )
|NORMAL

|VISUAL
|kbd:[V]
|NORMAL
|===

NOTE: kbd:[ESC] 是通用的“退出”按键。无论在什么模式下，按下 kbd:[ESC] 键都可以退出至NORMAL模式。



=== 1.1.2.INSERT

INSERT是Vi系编辑器中的**编辑模式**。在INSERT模式下，你可以写入或删除文本数据。就像其他编辑器一样。 +
按下 kbd:[ESC] 可以退出INSERT模式。

你肯定也注意到了，进入INSERT模式有不止一个快捷键。它们都可以正常进入INSERT模式，但光标位置会有所不同：

* I代表Insert，即插入，因此按下 kbd:[I] 进入INSERT模式时光标将会移动至当前选中字符的左边。
键入大写I( kbd:[SHIFT+I] )可以将光标移至当前行的开头位置并进入INSERT模式。
* A代表Add，即添加，因此按下 kbd:[A] 进入INSERT模式时光标将会移动至当前选中字符的右边。
键入大写A( kbd:[SHIFT+A] )可以将光标移至当前行的末尾并进入INSERT模式。
* O代表Open a new line，翻译过来就是“创建新的一行”，因此按下 kbd:[O] 进入INSERT模式时会在当前选中字符相应行的下方新建一行并将光标移至新行上。
键入大写O( kbd:[SHIFT+O] )则相反，将会在当前行的上方新建一行并将光标移至新行上进入INSERT模式。

NOTE: **大小写操作** +
在Vi系编辑器中，**任何操作都是分大小写的**，包括快捷键、命令、输入的字符等。
快捷键一般更多使用小写，大写快捷键的功能一般与小写相似，但有部分区别。 +
输入大写字符的其中一个方式就是按住Shift再按下那个字符，这也许是一种检测Shift修饰符的方法。
当然了，如果你开了CapsLock，那就是另一回事了。
