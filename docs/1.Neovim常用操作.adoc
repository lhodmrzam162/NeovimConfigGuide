= 1.Neovim常用操作

:experimental:



本篇将会讲解Neovim的常用操作。同样是很重要的一篇，至少咋用得会对吧。

NOTE: 别忘了，Neovim本身是一个Vim的分支。在基础操作这方面，Neovim与Vim几乎没有任何区别。
**如果你会使用Vim的话，本篇就可以放心跳过了。**






== 1.1.模式

**模式**是Vi系编辑器的精华所在。这个概念在第0篇已经提到过，这里要讲的是每个模式的具体操作方式。



=== 1.1.1.模式切换

大部分模式切换都在NORMAL模式下进行。

|===
|目标模式 |快捷键 |需求模式

|NORMAL（默认模式）
| `<Esc>`
|-

|INSERT（插入模式）
| `i` / `a` / `o` (大小写均可)
|NORMAL

|COMMAND
| `:`
|NORMAL

|VISUAL（可视模式）
| `v` / `V` / `<c-v>`
|NORMAL
|===

NOTE: `<Esc>` 是通用的“退出”按键。无论在什么模式下，按下 `<Esc>` 键都可以退出至NORMAL模式。



=== 1.1.2.INSERT

INSERT是Vi系编辑器中的**编辑模式**。在INSERT模式下，你可以写入或删除文本数据。就像其他编辑器一样。 +
按下 `<Esc>` 可以退出INSERT模式。

你肯定也注意到了，进入INSERT模式有不止一个快捷键。它们都可以正常进入INSERT模式，但光标位置会有所不同：

* I代表Insert，即插入，因此按下 `i` 进入INSERT模式时光标将会移动至当前选中字符的左边。
按下 `I` 可以将光标移至当前行的开头位置并进入INSERT模式。
* A代表Add，即添加，因此按下 `a` 进入INSERT模式时光标将会移动至当前选中字符的右边。
按下 `A` 可以将光标移至当前行的末尾并进入INSERT模式。
* O代表Open a new line，翻译过来就是“创建新的一行”，因此按下 `o` 进入INSERT模式时会在当前选中字符相应行的下方新建一行并将光标移至新行上。
按下 `O` 则相反，将会在当前行的上方新建一行并将光标移至新行上进入INSERT模式。



=== 1.1.3.COMMAND

COMMAND是Neovim进行非文本操作的主要模式。在COMMAND模式下可以输入Neovim命令。
在NORMAL模式下按下 `:` 即可进入。 +
COMMAND模式的命令极多，这里只介绍常用的一部分。
你也可以自行探索。你将发现许多好用的命令。

|===
|命令 |描述

|edit <文件/夹目录>
|编辑文件或选定文件夹。

|w
|保存当前文本。

|q
|退出当前窗口。

|wq
|保存并退出当前窗口。 ~(没有qw)~

|q!
|强行退出当前窗口(并放弃更改)。

|so
|重载Neovim(配置文件)。

|undo
|撤销。

|redo
|重做。

|checkhealth [插件名等]
|检查插件/nvim等的状态。

|!<command>
|在当前目录下运行CLI命令。

|luado
|运行单行lua脚本。有时会有大用。

|help [页面]
|查看帮助。请记住， `:help` 是你最好的朋友。
|===

更多原生命令可以在第1.5篇找到。但我们不建议你现在就去看，第1.5篇包含的是更多Neovim操作，现阶段你大概率用不到它们。 +
当你想继续钻研Neovim时再去看看吧。现在不是时候。在很多时候，我们可能会使用 `:xx` 来表示在命令模式下输入 `xx` 命令。这和社区里表示快捷键的做法有异曲同工之妙。



=== 1.1.4.VISUAL

VISUAL，顾名思义，在该模式下可以选择部分文本进行某些操作。 +
按下 `v` 即可在当前光标位置下进入VISUAL模式。

VISUAL模式下有2个“控制点”，这两个控制点中间的文本会被选中。
进入VISUAL模式时会自动在当前光标位置上设定一个“控制点”，另一个“控制点”则会被选中，移动光标的操作会转为移动这个“控制点”的操作。
按下 `o` 可以在两个“控制点”之间来回切换。

按下 `V` 即可进入VISUAL LINE模式，该模式与VISUAL模式没有多少区别，但选中的是行而不是字符。

按下 `<C-v>` 可以进入VISUAL BLOCK模式，该模式与VISUAL模式同样没有多少区别，但VISUAL BLOCK模式选中的部分是“视觉上的部分”，而不是常规文本部分。解释起来很困难，但只要自己试一试就会明白了。

IMPORTANT: 在VISUAL BLOCK模式下会默认英文字符与中文字符是完美的2:1比例。绝大多数等宽字体都是如此。
但如果出现了一些“特殊情况”，Neovim依旧是能够处理的。 +
如果出现显示错位的情况，可以考虑换一个英文字符与中文字符宽度完美2:1的字体，也就是等宽字体。
绝大部分用于代码编辑器或终端的字体都是等宽字体。例如许多人都在使用的Maple Mono。






== 1.2.快捷键

Vi系编辑器的一大特点是可以用键盘完成任何操作，这里介绍一些较为常用的快捷键。
虽然上手会比较难，但一旦熟练，编辑速度将会快非常多。

.光标移动(NORMAL)
* `w` ：按下 `w` 键可以让光标前进到下一个“词”的开头。词的分割一般是按照符号和空白符的，符号在此处单独视为一个词，而空白符不是。
按下 `W` 的效果大差不差，但键入大写W时会把标点符号也视作一个“词”的一部分，跳转至下一个“空白符”分隔的“词”的开头。
* `e` ：与 `w` 相似，但 `e` 会将光标前进到下一个“词”的末尾。
按下 `E` 的效果变化与大写W同理。
* `b` ：与 `w` 类似，但 `b` 会将光标后退至上一个词，而不是当前词。
按下 `B` 的效果同理。
* `h` `j` `k` `l` ：这4个按键与方向键的作用完全相同，分别对应左下上右。
至于它的存因，这实际上是历史遗留的产物。
这一套由Vi系编辑器首创的按键方案及其有名，在键盘上还没有方向键时，Vi系编辑器就可以使用这4个按键移动方向。
直到现在，这4个按键的作用仍被保留。许多TUI程序直到现在仍然推荐使用HJKL移动光标。

.文本操作(NORMAL)
* `x` ：删除光标处的字符。
* `X` ：删除光标前的字符。
* `d` ：删除某一部分。后面接上作用区域，例如 `w` 。
* `c` ：更改一部分内容。所谓更改，其实是删除相应部分并进入INSERT模式。后面接作用区域。
* `r` ：替换单个字符。
* `R` ：进入连续替换模式。具体作用请自行领悟。
* `~` ：不是很常用。反转选中字符的大小写。对非英文字符无效。
* `.` ：重复上次操作。具体逻辑很难解释，只能自行体会。

.复制粘贴&撤销(NORMAL)
* `y` ：复制。后面接作用区域。
* `p` ：(在光标后)粘贴。
* `P` ：(在光标前)粘贴。
* `u` ：撤销。
* `<C-r>` ：重做。

.查找(NORMAL)
* `/` ：(向下)查找某些内容。键入后光标会跳转至COMMAND行里，此时输入要查找的内容，相应内容将会高亮显示。
* `?` ：(向上)查找某些内容。
* `n` / `N` ：跳转至下一个/上一个搜索匹配项。
* `*` ：快速查找光标处的词。

.VISUAL模式专用(VISUAL系通用)
* `o` ：在两个控制点之间来回切换。
* `d` / `x` ：删除选中内容。
* `y` ：复制选中内容。
* `c` ：不用多说了。VISUAL模式里的更改操作，作用区域为选中部分。
* `~` ：不是很常用。反转选中部分的大小写。对非英文字符无效。
* `u` / `U` ：不是很常用。将选中部分转换为小写/大写。**仅在VISUAL模式下生效。**
* `p` ：使用剪贴板的文本覆盖选中部分。
* `:` ：对选中部分执行命令。该情况下的很多命令与常规命令不同。

.VISUAL-BLOCK特殊快捷键(仅VISUAL-BLOCK)
* `I` :在所有被选中行最左侧的位置插入文本。按下 `<esc>` 后将对所有行生效。 `A` 同理。 +
注：只有键入大写 `I` `A` 才会生效。
* `r` ：使用同一字符替换选中部分所有字符。如果有字符宽度不等，将会“依据视觉效果处理”。 +
例如，如果用英文字符替换一些中文字符，那么每个中文字符的位置将会被替换为2个英文字符。
