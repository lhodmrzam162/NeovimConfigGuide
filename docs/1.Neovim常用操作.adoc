= 1.Neovim常用操作

:experimental:



本篇将会讲解Neovim的常用操作。同样是很重要的一篇，至少咋用得会对吧。

NOTE: 别忘了，Neovim本身是一个Vim的分支。在基础操作这方面，Neovim与Vim几乎没有任何区别。
**如果你会使用Vim的话，本篇就可以放心跳过了。**






== 1.1.模式

**模式**是Vi系编辑器的精华所在。这个概念在第0篇已经提到过，这里要讲的是每个模式的具体操作方式。



=== 1.1.1.模式切换

大部分模式切换都在NORMAL模式下进行。

|===
|目标模式 |快捷键 |需求模式

|NORMAL
|kbd:[ESC]
|-

|INSERT
|kbd:[I] / kbd:[A] / kbd:[O]
|NORMAL

|COMMAND
|kbd:[:] ( kbd:[SHIFT+;] )
|NORMAL

|VISUAL
|kbd:[V] / kbd:[CTRL+V]
|NORMAL
|===

NOTE: kbd:[ESC] 是通用的“退出”按键。无论在什么模式下，按下 kbd:[ESC] 键都可以退出至NORMAL模式。



=== 1.1.2.INSERT

INSERT是Vi系编辑器中的**编辑模式**。在INSERT模式下，你可以写入或删除文本数据。就像其他编辑器一样。 +
按下 kbd:[ESC] 可以退出INSERT模式。

你肯定也注意到了，进入INSERT模式有不止一个快捷键。它们都可以正常进入INSERT模式，但光标位置会有所不同：

* I代表Insert，即插入，因此按下 kbd:[I] 进入INSERT模式时光标将会移动至当前选中字符的左边。
键入大写I( kbd:[SHIFT+I] )可以将光标移至当前行的开头位置并进入INSERT模式。
* A代表Add，即添加，因此按下 kbd:[A] 进入INSERT模式时光标将会移动至当前选中字符的右边。
键入大写A( kbd:[SHIFT+A] )可以将光标移至当前行的末尾并进入INSERT模式。
* O代表Open a new line，翻译过来就是“创建新的一行”，因此按下 kbd:[O] 进入INSERT模式时会在当前选中字符相应行的下方新建一行并将光标移至新行上。
键入大写O( kbd:[SHIFT+O] )则相反，将会在当前行的上方新建一行并将光标移至新行上进入INSERT模式。

NOTE: **大小写操作** +
在Vi系编辑器中，**任何操作都是分大小写的**，包括快捷键、命令、输入的字符等。
快捷键一般更多使用小写，大写快捷键的功能一般与小写相似，但有部分区别。 +
输入大写字符的其中一个方式就是按住Shift再按下那个字符，这也许是一种检测Shift修饰符的方法。
当然了，如果你开了CapsLock，那就是另一回事了。



=== 1.1.3.COMMAND

COMMAND是Neovim进行非文本操作的主要模式。在COMMAND模式下可以输入Neovim命令。
在NORMAL模式下键入 `:` ( kbd:[SHIFT+;] )即可进入。 +
COMMAND模式的命令极多，这里只介绍常用的一部分。

|===
|命令 |描述

|edit <文件/夹目录>
|编辑文件或选定文件夹。

|w
|保存当前文本。

|q
|退出当前窗口。

|wq
|保存并退出当前窗口。 ~(没有qw)~

|q!
|强行退出当前窗口(并放弃更改)。

|so
|重载Neovim(配置文件)。

|undo
|撤销。

|redo
|重做。

|help [页面]
|查看帮助。请记住，:help是你最好的朋友。
|===

更多原生命令可以在第1.5篇找到。但我们不建议你现在就去看，第1.5篇包含的是更多Neovim操作，现阶段你大概率用不到它们。 +
当你想继续钻研Neovim时再去看看吧。现在不是时候。



=== 1.1.4.VISUAL

VISUAL，顾名思义，在该模式下可以选择部分文本进行某些操作。 +
按下 kbd:[V] 即可在当前光标位置下进入VISUAL模式。

VISUAL模式下有2个“控制点”，这两个控制点中间的文本会被选中。
进入VISUAL模式时会自动在当前光标位置上设定一个“控制点”，另一个“控制点”则会被选中，移动光标的操作会转为移动这个“控制点”的操作。
按下 kbd:[O] 可以在两个“控制点”之间来回切换。

键入大写V( kbd:[SHIFT+V] )即可进入VISUAL LINE模式，该模式与VISUAL模式没有多少区别，但选中的是行而不是字符。

按下 kbd:[CTRL+V] 可以进入VISUAL BLOCK模式，该模式与VISUAL模式同样没有多少区别，但VISUAL BLOCK模式选中的部分是“视觉上的部分”，而不是常规文本部分。解释起来很困难，但只要自己试一试就会明白了。

IMPORTANT: 在VISUAL BLOCK模式下会默认英文字符与中文字符是完美的1:2比例。绝大多数等宽字体都是如此。
但如果出现了一些“特殊情况”，Neovim依旧是能够处理的。

.光标移动(NORMAL)
* kbd:[W] ：按下 kbd:[W] 键可以让光标前进到下一个“词”的开头。
键入大写W( kbd:[SHIFT+W] )的效果大差不差，但键入大写W时会把标点符号也视作一个“词”的一部分，跳转至下一个“空白符”分隔的“词”的开头。
* kbd:[E] ：与 kbd:[W] 相似，但 kbd:[E] 会将光标前进到下一个“词”的末尾。
键入大写E( kbd:[SHIFT+E] )的效果变化与大写W同理。
* kbd:[B] ：与 kbd:[W] 类似，但 kbd:[B] 会将光标后退至上一个词，而不是当前词。
键入大写B( kbd:[SHIFT+B] )的效果同理。
* kbd:[H] kbd:[J] kbd:[K] kbd:[L] ：与方向键相同，但Vi系编辑器同样支持使用这4个按键移动光标。
