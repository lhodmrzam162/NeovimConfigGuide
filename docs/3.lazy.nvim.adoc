= 3.lazy.nvim

基础配置完成后，接下来我们开始真正地安装并配置插件。 +
我们的第一步是安装并学习使用 `lazy.nvim` 包管理器。

NOTE: **包管理器** +
包管理器是用于管理软件包的工具，除了Windows平台外一般都较为常用。几乎任何Linux发行版都会预装一个原生包管理器。 +
Neovim中的包管理器作用类似，但管理的是Neovim插件而不是软件包。

TIP: 本文档重点讲解的是依赖于lazy.nvim包管理器的配置，Neovim0.12中也引入了一个官方包管理器，但作者还是更推荐使用lazy.nvim，因为它更成熟且功能更丰富。



== 3.1.安装

lazy.nvim的安装教程可以在link:https://lazy.folke.io/[folke的官方网站]找到。此处就不再过多赘述。如果看不懂英语请使用翻译器。 +
作者在此特别推荐使用多文件方案，你总不可能把一堆配置放一个文件里对吧。另外，lazy.nvim的设计会让你必须使用多文件。



== 3.2.配置文件结构

配置文件的结构非常重要，**一定要严格遵守你自己的配置规则，否则会让你的配置变成鸡窝。** +
当然了，你自己的配置才是最好的，配置文件的结构当然也不例外。
这是一个你需要重点考虑的东西，请记住，在配置写得比较多后，修改结构的时间成本是巨大的，
因此**一定要尽量在开始前就确定好你的配置文件结构**。

如果你对某些东西有点犹豫，亦或是想找个参考，以下是作者自己使用的一套结构。但尽量别全部照搬。

----
runtimepath
│
├─lua
│ ├─config  # <1>
│ │ ├─(GROUP_NAME).lua  # <4>
│ │ └─(plugin_name).lua  # <5>
│ ├─main  # <2>
│ │ ├─options.lua
│ │ └─keymaps.lua
│ └─plugins  # <3>
│   ├─(GROUP_NAME).lua
│   └─(plugin_name).lua
└─init.lua
----
<1> 放置插件配置的目录。所有插件的配置均放在此处。
<2> 基础配置，比如Neovim的原生配置及按键绑定。
<3> lazy.nvim指定的插件声明文件夹。插件声明**只能**放在此处。
<4> 复合配置文件，即单个配置文件中同时包含了多个插件的配置，文件名为全大写(除了 `.lua` )。plugins目录下的同理。
<5> 单独配置文件，即单个配置文件配置单个插件，文件名为全小写。plugins目录下的同理。



== 3.3.插件声明

lazy.nvim包管理器的插件声明方式与其他包管理器略有不同。 +
lazy.nvim启动时会自动在 `/lua/plugins` 目录下寻找.lua文件。这些.lua文件应直接return一个或多个组，return的内容正是插件声明信息。

以下是一个插件声明示例。

[source,lua]
----
-- /lua/plugins/VISUAL.lua
return {  # <1>
  -- lualine.nvim
  {
    "nvim-lualine/lualine.nvim",  # <2>
    dependencies = { "nvim-tree/nvim-web-devicons" },  # <3>
    priority = 100,  # <4>
  },
  
  -- rainbow-delimiters.nvim
  {
    "hiphish/rainbow-delimiters.nvim",
    lazy = false,  # <5>
  }
}
----
<1> 单个.lua文件可以return多个组，这个示例便是。记得加","。
<2> 插件的远程仓库地址。如果是github链接，则可以省略"https://github.com/"这一部分。不用加 `.git` 。
<3> 插件的依赖项，你可以理解为"前置模组"。当然了可以有多个依赖项。如果出现了依赖重复的情况，lazy.nvim会自动处理。
<4> 插件的加载权重，权重越高，插件的加载优先级就越高，便会被越早加载。
<5> lazy.nvim的LazyMode，同时也是lazy.nvim包管理器的特色之一。当此项被开启，插件将只会在需要的时候被加载。

IMPORTANT: 并不是所有插件都能开启LazyMode。一般来说，插件的作者会明确告诉你这个插件能否使用LazyMode。 +
如果你给本不能开启的插件强行开启，可能会出现一些未知问题，例如插件不被加载。 +
更推荐的做法是看作者是否建议开启。如果作者没有单独说明，你可以去亲自尝试或者永不开启。

TIP: 声明一个新插件后，你可以直接 `:Lazy` 并键入 `I` ，然后lazy.nvim将会直接安装它，无需重启Neovim。
